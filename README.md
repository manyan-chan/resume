# My LaTeX Resume

This repository contains the LaTeX source code for my professional resume. It utilizes GitHub Actions to automatically compile the `.tex` file into a PDF document whenever changes are pushed to the `main` branch.

[![Compile Resume PDF](https://github.com/manyan-chan/resume/actions/workflows/compile-resume.yml/badge.svg)](https://github.com/manyan-chan/resume/actions/workflows/compile-resume.yml)

## Features

*   **LaTeX Source:** The resume is written in LaTeX for precise formatting, easy version control, and separation of content from presentation.
*   **Automated Builds:** A GitHub Actions workflow (`.github/workflows/compile-resume.yml`) automatically compiles `resume.tex` using `pdflatex` (via the `xu-cheng/latex-action`).
*   **PDF Artifacts:** The compiled `resume.pdf` is uploaded as a workflow artifact, making the latest version easily accessible.

## How to Get the Latest PDF

The compiled PDF is not stored directly in the repository but is generated by the GitHub Action. To download the latest version:

1.  Navigate to the **Actions** tab of this repository.
2.  Click on the latest successful workflow run listed under "Compile Resume PDF" (usually the top one).
3.  On the summary page for that run, scroll down to the **Artifacts** section.
4.  You should see an artifact named `Resume_PDF`. Click on it to download a `.zip` file.
5.  Unzip the downloaded file to find the `resume.pdf`.

## Modifying the Resume

1.  Clone this repository to your local machine.
2.  Edit the `resume.tex` file using your preferred LaTeX editor.
3.  Commit your changes.
4.  Push the changes back to the `main` branch on GitHub.
5.  The GitHub Action will automatically trigger, compile the new version, and make the updated PDF available as an artifact (see instructions above).

## Technology

*   **LaTeX:** Document preparation system.
*   **pdflatex:** Specific LaTeX engine used for compilation.
*   **GitHub Actions:** Automation platform for CI/CD.
*   **xu-cheng/latex-action@v3:** The specific GitHub Action used for LaTeX compilation.
